# Exhibition carousel asset provenance

The 24 WebP files in this directory are the same optimised exhibition-photo set used by the M-CORE Connected Britain 2026 landing page. They were copied locally into this repository for reliable production delivery; runtime code does not load Google Drive URLs.

These are deliberately from a range of different exhibitions, not only BVM 2026. The carousel sits at the top of the page as an authority strip — the point is breadth, showing The Brandologist Co. working across multiple events. Keep the alt text generic ("Exhibition moment N") rather than naming a specific event, so no single show is implied.
